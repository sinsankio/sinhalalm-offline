# Quantization Comparison: Answers of the Candidate Variants

The RQ1 evaluation showed that every plain 4-bit variant of SinhalaLLM-1.7B loses far more quality than the 2% perplexity gate allows, and that keeping a single weight matrix in full precision recovers most of the loss ([rq1-quantization.md](findings/rq1-quantization.md)). In this document, we list the answers of the two resulting 4-bit candidates next to the fp32 reference answers, so that the choice of the shipped variant can be made from the answers themselves and not only from perplexity.

### How the answers were produced

- **Questions** — the ten golden questions from `golden/prompts.json`, in the model's ChatML format, without ZWJ normalization.
- **Decoding** — greedy decoding with ONNX Runtime 1.31.0 on the CPU, up to 64 new tokens or until a stop token.
- **fp32 (reference)** — the golden answers produced by the reference toolchain, which the fp32 ONNX model reproduces exactly.
- **q4-v0** — 4-bit weights (block size 32, symmetric), with the value projection of layer 0 kept in fp32 and the output head tied to the fp32 embedding.
- **q4-v0-small** — as q4-v0, but with the output head untied and quantized to 4 bits and the embedding lookup quantized to 4 bits.
